Implemented CSRF protection.

----------

Implemented CSRF protection:

-As promising in a few previous commits, CSRF is now successfully implemented.

-From now on, any request that doesn't use the GET method requires a valid CSRF token,
which can be included with the request in either of the following ways:
	1. 'request header' whose name is set to 'X-CSRF-TOKEN',
	2. 'request parameter' whose name is set to '_csrf'.

-Added GET '/csrf' path, which can be used for manually requesting for the CSRF token.
