1. Implemented JWT token:

-Users can now maintain their login state after closing the session
with the help of JWT token.

-JWT token in the 'Authorization' header that starts with 'Bearer '
will get the higher priority over token sent with Cookies. In other
words, the server will rely on the header if available, or it will
rely on Cookies as a fallback when there's no 'Authorization' header
that starts with 'Bearer '.

-JWT token is located in Cookies by default.

-The age of the token is set to 90 minutes.

-The server will ask the browser to delete the token in the Cookies
when users log out.
