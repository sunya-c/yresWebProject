1. Spring Security:

-Log in system is now based on Spring Security (used to be manually-written filters).

-Implemented login form authentication and basic authentication.

-Password stored in the database is now hashed with 'Bcrypt' algorithm, enhancing security
to the next level.

-Added FilterSetCookie to centralize Cookies configuration.

-Enhanced various security factors which include CORS and explicitly mentioning SameSite,
Secure, and HttpOnly Cookies flags. (CSRF will be configured in the upcoming commit)
(CookieManager.createCookie() method can be used for a quick Cookies creation with these
security Cookies flags)


2. Fixed Cookies bug:

-Fixed a bug where there're occasionally duplicate Cookies saved in the browser. This was
fixed by mentioning the correct cookies path.
